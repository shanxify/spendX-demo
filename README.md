## 📖 About

**spendX** is a modern personal finance web application that helps users manage and understand their UPI spending.

Users can upload transaction statement PDFs from **PhonePe**, **Google Pay**, or **Paytm**, and spendX automatically extracts, categorizes, and stores transactions securely while presenting meaningful spending insights through an interactive dashboard.

---

## ✨ Features

- 📄 Upload UPI statement PDFs
- 📱 Supports PhonePe, Google Pay & Paytm
- 🔍 Automatic transaction extraction
- 🏷️ Smart expense categorization
- 📊 Interactive analytics dashboard
- 📈 Monthly spending trends
- 🛒 Category-wise expense analysis
- 🏪 Top merchant insights
- 📋 Complete transaction history
- 🔐 Secure Google Authentication
- ☁️ Cloud-based data storage
- 📱 Responsive user interface

## 📄 How It Works

1. Sign in with Google
2. Upload a UPI statement PDF
3. Select the payment provider
4. Transactions are extracted automatically
5. Expenses are categorized
6. Data is securely stored
7. View spending insights through interactive dashboards

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/shanxify/spendX.git
```

Navigate to the project

```bash
cd spendX/money-tracker
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm start
```
